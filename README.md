# Cross-Strait Phrase Switch

**版本：** 1.0.1

在台灣／中國大陸用詞之間轉換，不只是繁簡字形。

## 需求

- WordPress 6.0+
- PHP 8.0+（部分外掛標示 7.4+）

## 安裝

1. 下載本倉庫 zip，或 clone 後壓縮成資料夾
2. 上傳到 `wp-content/plugins/cross-strait-phrase-switch/`
3. 在後台啟用外掛
